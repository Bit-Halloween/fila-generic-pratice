# Praticando Fila Genérica em Java

Exercício desenvolvido durante a aula de Organização e Orientação a Objetos.

## Objetivo

Praticar o uso de tipos genéricos em Java por meio da implementação de uma fila `Fila<T>`.

A fila permite:

- Adicionar elementos.
- Consultar o primeiro elemento sem removê-lo.
- Remover o próximo elemento.
- Verificar se a fila está vazia.
- Consultar a quantidade de elementos.
- Listar os elementos armazenados.

## Classes utilizadas

- `Fila<T>`: classe genérica responsável pela fila.
- `Cliente`: representa um cliente com nome e CPF.
- `Chamado`: representa um chamado com número e descrição.
- `Pedido`: representa um pedido com número e valor.
- `Main`: demonstra o funcionamento das filas.
